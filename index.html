01 Research

Upcoming · from 01/2027

Dynamics of the pullback metric during learning

The pullback metric describes the geometry a network’s map induces on its inputs: which directions it stretches and which it compresses. This project studies how that geometry evolves as the network learns.

Research Assistant, Group for Neural Theory, ENS-PSL, with A. Cayco Gajic.

M.Sc. thesis · 02/2026 – 06/2026

Can a simple model explain economics?

The thesis treats firm growth as a stochastic many-body problem: a relative generalized Lotka–Volterra model of competing firms whose steady state reproduces the non-Gaussian growth and volatility statistics measured in Compustat firm-level data. Because the full many-firm dynamics are intractable, I derived a dynamical mean-field theory (DMFT) that reduces the problem to a self-consistent single-firm stochastic process, validated the solver against agent-based simulations, and open-sourced the Python package behind it.

L. Furlanetto (2026). M.Sc. thesis, Centre d’Économie de la Sorbonne, Université Paris 1 Panthéon-Sorbonne. Supervisors: F. Aguirre-López, L. Dall’Asta. [PDF] [code]

02 Software

Backtes.to — Financial Analysis SaaS Core Developer, 2-person team 02/2026 – Present · backtes.to

Backtes.to is a European ETF portfolio backtester: you build an allocation, run a historical backtest, and get Compound Return, volatility and Sharpe out of it. The platform is built in JavaScript and Next.js on a Supabase (Postgres) backend and serves 50,000+ monthly visits. My focus has been on the backend — parallelizing backtest execution across servers and cutting the compute cost of scanning millions of rows of financial data.

Ruut Functions — Rust numerics library Maintainer Ongoing · crates.io/crates/ruut-functions

High-performance Rust library for numerical integration and symbolic differentiation; 10,000+ downloads, built around memory safety and computational speed.
